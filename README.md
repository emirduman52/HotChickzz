# HOT CHICKZZZ — Chick It Out

Landingpage für Hot Chickzzz, Streetfood in Frankfurt am Main (Leipziger Str. 85).

## Live-Preview

https://emirduman52.github.io/HotChickzz/

## Struktur

| Datei | Zweck |
| --- | --- |
| `Hot Chickzzz.dc.html` | Quelldatei (Design-Composer-Format) |
| `index.html` | Kopie der Quelldatei — Einstiegspunkt für GitHub Pages |
| `support.js` | Runtime für das `x-dc`-Format (generiert, nicht editieren) |
| `uploads/` | Bildmaterial (Logo) |

Änderungen in `Hot Chickzzz.dc.html` vornehmen und anschließend nach `index.html` kopieren:

```sh
cp "Hot Chickzzz.dc.html" index.html
```

## Features

- Sticky Header mit Burger-Menü unter 820px
- Menü mit Kategorie-Filter (Bites, Wingzzz, Burgerzzz, Sides & Saucen, Getränke)
- Bestell-Sektion mit Direktlinks zu Wolt und Uber Eats
- Standort mit OpenStreetMap-Einbettung und Routen-Link
- Vollständig responsiv (Mobile bis Desktop), `prefers-reduced-motion` respektiert
